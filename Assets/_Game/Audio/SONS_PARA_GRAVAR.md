# Sons para gravar — Buteco dos Devs: A Guerra Púnica

Regra da jam: **todos os sons gravados pela galera do Buteco** (nada de IA).
Grave no celular, salve em **.wav** (ou .mp3) e coloque em `Assets/_Game/Audio/SFX/` (música em `Audio/Music/`).
Depois é só abrir `Assets/_Game/Audio/SoundLibrary.asset` no Unity e **arrastar cada arquivo para o campo com o mesmo nome**.

| Campo no SoundLibrary | O que gravar | Onde toca |
|---|---|---|
| Rua | Moe gritando **"RUA!!!"** (bem bravo) | soundboard, TIMEOUT, expulsão |
| Aplausos | galera aplaudindo / "AEEE" | soundboard |
| Vaias | "UUUUUH" | soundboard |
| Risadas | "KKKKK" / risada em grupo | soundboard |
| Burp | arroto | soundboard |
| IsqueiroFalha | "tsc tsc" de isqueiro falhando | Pedro fumando |
| IsqueiroAcende | isqueiro acendendo de vez | Pedro fumando |
| DardoNerf | "pew" de Nerf | bagunça da chegada |
| DardoAcerta | "ai!" / tapinha | bagunça da chegada |
| CanecaMesa | caneca batendo na mesa | Julio bebendo |
| GolpeSwing | "fwoosh" (vento de golpe) | ataques |
| GolpeAcerto | pancada / "tum" | acerto |
| PlayerDano | "ai" do Dev | player apanhando |
| Parry | "clang" metálico | defesa no tempo certo |
| Dash | "fwip" rápido | dash |
| PortaAbre | porta rangendo | chegada / Pedro saindo e voltando |
| Timeout | voz do Pedro: **"TIMEOUT."** | habilidade do Pedro |
| BoraGrito | Pedro: **"BORA!"** + galera gritando | início da guerra |
| MusicaBar | música de fundo do bar (loop, pode ser violão/assobio) | Buteco |

Dica: 0,5–2 s por efeito, sem silêncio no começo. Pode mandar vários "RUA!!!" diferentes — depois dá para sortear.
